## 🎮 QUICK START

### 🐍 **Python Main Controller**
```bash
# Initialize the entire system
python3 main.py init

# Check system status
python3 main.py status

# Deploy contracts
python3 main.py deploy --network base

# Inject liquidity
python3 main.py inject --network base --amount 1.0

# Auto mode (full cycle)
python3 main.py auto --network base --amount 1.0
```

### 🖥️ **Interactive CLI**
```bash
# Start interactive mode
npm run interactive

# Or use direct commands
npm run cli status
npm run cli inject --network base --amount 1.0
npm run cli monitor --interval 10
```

### 🌐 **REST API**
```bash
# Start API server
npm run api

# Available endpoints:
# GET  /health - System health check
# POST /auth/token - Generate auth token
# GET  /system/status - Detailed system status
# POST /liquidity/inject - Inject liquidity
# GET  /networks - Supported networks
```
